## ✨ Overview

This portfolio is built with plain HTML, CSS and JavaScript (no framework, no build step) so it
loads fast and is easy to fork, host on GitHub Pages, or edit directly. It serves as:

- A **digital resume** — education, internships and technical skills at a glance
- A **project showcase** — real, linked GitHub repos with measurable outcomes
- A **credentials hub** — certifications and hackathon/achievement proof
- A **contact point** — a working contact form plus direct links

## 🧩 Sections

| Section | What's there |
|---|---|
| Hero | Typing-effect role intro, resume download, social links |
| About | Bio, quick stats, XP bar, mini education/experience timeline |
| Skills | Filterable skill cards (Languages, Frontend, Backend & DB, AI/ML) with animated progress bars |
| Experience | Internship & education timeline with linked certificates |
| Projects | 4 flagship, GitHub-linked projects with real metrics |
| Certifications | Clickable gallery with a lightbox viewer |
| Achievements | Hackathon wins, SIH finalist status, national ranking — each linked to proof |
| Contact | Validated form (Formspree) + direct contact details |

## 🛠️ Tech Stack

- **Structure/Style:** HTML5, CSS3 (custom properties, no framework)
- **Interactivity:** Vanilla JavaScript — IntersectionObserver-based scroll reveals, animated
  counters/progress bars, 3D tilt cards, magnetic buttons, custom cursor, a draggable terminal
  easter egg
- **Type effect:** [Typed.js](https://github.com/mattboldt/typed.js/)
- **Icons:** [Font Awesome](https://fontawesome.com/)
- **Fonts:** Sora, Inter, JetBrains Mono (Google Fonts)
- **Forms:** [Formspree](https://formspree.io/)

## 🚀 Running Locally

No build step required — just open it:

```bash
git clone https://github.com/siddharthcode-24/Portfolio2.git
cd Portfolio2
open index.html      # or double-click the file
```

Or serve it locally for a closer-to-production preview:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
